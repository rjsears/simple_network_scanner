Design Summary

Linux Desktop Network Scanner - Final Design

Technology Stack

Framework: PySide6 (Qt6 for Python) Language: Python 3.10+ Styling: Qt Style Sheets (QSS) - matching macOS theme Packaging: .deb package + AppImage

Visual Design

  • Teal color scheme (#008c9e primary, #4dc0cc accent)
  • Card-based layout with rounded corners and subtle shadows
  • Tech grid background with map overlay
  • Monospace typography throughout
  • Status indicator capsule in header
  • Clickable summary pills (UP/DOWN/NET/BCAST)

Features

Core Scanning Start IP, host count, CIDR input, parallel ping, reverse DNS
Progress Display Real-time progress bar with count
Results Table IP, Status (color-coded), Hostname columns
Summary & Filtering Clickable pills to filter by status
Export NEW: Save results to CSV or JSON
Presets NEW: Save/load scan configurations
About Dialog Version, author, GitHub link
