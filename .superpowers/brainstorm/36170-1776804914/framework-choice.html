Linux Desktop Framework

Which approach should we use for your Ubuntu 25 network scanner?

A

GTK4 + Python (PyGObject)

Native GNOME/Ubuntu look and feel. Integrates naturally with Ubuntu 25's desktop environment. Smaller install size, no extra runtimes needed. Uses Python like your CLI scanner.

Pros

  • Native Ubuntu appearance
  • Lightweight
  • Python-based (consistent with CLI)

Cons

  • Less styling flexibility
  • Different look than macOS version
B

Qt6 / PySide6

Polished, professional cross-platform look. More control over styling - can closely match the macOS version's aesthetic. Mature, battle-tested framework.

Pros

  • Excellent styling control
  • Can match macOS look
  • Professional appearance

Cons

  • Larger dependency (~100MB)
  • Not native GNOME style
C

Tauri (Rust + Web)

Modern web-based UI with Rust backend. Smaller than Electron (~10MB vs ~150MB). Can pixel-perfectly match macOS styling using HTML/CSS.

Pros

  • Exact macOS style match possible
  • Modern stack
  • Small binary size

Cons

  • Requires Rust toolchain
  • Different tech stack

Recommendation: Qt6/PySide6 offers the best balance - professional polish, styling flexibility to match your macOS app, and Python consistency.
