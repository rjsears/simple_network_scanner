Feature Scope

The macOS app has these features. Should the Linux version match exactly, or add/change anything?

Current macOS Features

Scan Parameters
Start IP, Host Count, CIDR input
Progress Bar
Real-time scan progress
Results Table
IP, Status, Hostname columns
Summary Pills
Clickable UP/DOWN/NET/BCAST counts
Filter Sheet
View hosts by status
About Dialog
Version info, author, GitHub link
A

Exact Feature Match

Same features as macOS - no more, no less. Consistent experience across platforms.

B

Add Export Feature

Match macOS + add ability to export results to CSV/JSON. Useful for documentation and reporting.

C

Add Network Presets

Match macOS + save/load scan presets (favorite subnets). Good for repeated scans of same networks.

D

Add Both Export + Presets

All macOS features plus export and presets. Most capable version.
